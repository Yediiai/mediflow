# MediFlow — Next.js Healthcare Technology Landing Page Application

A calm, clinical healthcare SaaS landing application for modern clinic management, intelligent appointment scheduling, paperless digital intake, and patient engagement.

## 🚀 Port & Development

This application runs on port **9003**:

```bash
npm install
npm run dev
```

Visit: `http://localhost:9003`

## 📄 Pages Included (4 Fully Designed Pages)

1. **Home / Landing Page (`/`)**:
   - Hero section: "Better Care Starts With Better Technology"
   - Interactive Clinic Management Dashboard Preview (patient queue, room tracking, intake rates)
   - Patient communication benefits (two-way secure SMS, automated reminders)
   - Clinician testimonials and workflow metrics
2. **Solutions (`/solutions`)**:
   - Solutions tailored across clinical disciplines (Primary Care, Pediatrics, Dermatology, Cardiology)
   - Multi-provider scheduling and exam room allocation
   - Paperless mobile intake and insurance card photo OCR
3. **Platform & Security (`/platform`)**:
   - Role-Based Access Control (RBAC) inspector for Physicians, Nurses, Front Desk, and Billing
   - AES-256 encryption at rest, TLS 1.3 in transit, and immutable audit logs
   - HL7 FHIR v4 interoperability connectors (Epic, Cerner, AthenaHealth)
   - BAA-ready compliance framework
4. **Book a Demo (`/contact`)**:
   - Practice Advisory & Guided Demo Request Form with React Hook Form + Zod validation
   - Provider count guidance and clinical specialty selector

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Medical Teal & Clinical Blue theme)
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod validation
